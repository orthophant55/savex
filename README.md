# savex
This is Orthophant’s first project.

As baseball continues to grow in popularity, more fans are looking for deeper insights, better analysis, and more meaningful content around the game. However, truly high-quality articles, columns, and educational resources are still surprisingly hard to find.

This project aims to fill that gap by building a website dedicated to baseball knowledge, theory, and analysis. By combining machine learning techniques with large language models, the platform will provide in-depth insights, data-driven breakdowns, and original AI-assisted articles for fans who want more than surface-level baseball content.
